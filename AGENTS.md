# Repository instructions

Follow [Development and maintenance](docs/development.md) for validation,
publication, runtime adoption, and periodic API-key variant maintenance. These
shared requirements apply to agents as well as human contributors. When generated
review output changes, also follow the linked
[review presentation QA checklist](docs/review-presentation-qa.md).

## Agent execution

Retain long-running command handles, logs, and final status before considering
reruns. Keep work within the requested scope and report the exact candidate and
any skipped, failed, or pending coverage. Do not initiate reviews or mark ready
without the applicable authorization. Never bypass denied access; report the
blocker and hold transitions that require the missing evidence.
