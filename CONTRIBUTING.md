# Contributing

This is an experimental runtime with no commitment to ongoing support.
Start with the [consumer guide](docs/consumer-workflows.md),
[review contract](docs/review-guide.md), and
[validation boundaries](docs/validation.md).

## Proposing changes

Explain the problem, expected behavior, and intended scope. Runtime changes and
consumer adoption are separate reviewed changes. Use sanitized examples and keep
credentials, private project content, and exploit details out of public issues
and pull requests. See [SECURITY.md](SECURITY.md) for private vulnerability reporting.

## Local checks

Development commands, validation requirements, and the repeatable presentation
[gallery procedure and visual checklist](AGENTS.md#review-presentation-gallery)
live in [AGENTS.md](AGENTS.md#development-and-validation).

For experimental API-key variant maintenance, follow the
[repository instructions](AGENTS.md#api-key-variant-maintenance).
